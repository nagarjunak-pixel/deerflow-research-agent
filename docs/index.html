Sub-Agent Capabilities

📋

Planner Agent

Decomposes research questions into structured sub-tasks. Supports quick (2), standard (4), and deep (6+) research depths.

🔍

Searcher Agent

Real web search via DuckDuckGo with graceful mock fallback. Returns structured findings with sources and timestamps.

🧠

Analyzer Agent

Synthesizes all findings into a professional markdown report with executive summary, per-topic analysis, and methodology.

💾

Context Store

JSON-based persistent memory. Store/recall any context across sessions. Resume interrupted research from any checkpoint.

♻

Session Resume

Pick up where you left off. The agent detects partial sessions and resumes from the last completed phase.

📊

Auto Reports

Generates structured markdown reports with executive summary, source citations, and methodology documentation.

Quick Start

1

Clone & Install

Terminal
git clone https://github.com/nagarjunak-pixel/deerflow-research-agent.git
cd deerflow-research-agent
pip install -r requirements.txt
2

Run Research

Terminal
# Quick research
python research_agent.py "AI regulation in India"

# Deep research
python research_agent.py --topic "Telugu tech startups" --depth deep

# Resume session
python research_agent.py --resume abc12345
